Three core concepts covered during Session 01:
1-The difference between Git and GitHub:
-Git is a version control tool that runs on your computer
It tracks changes to your files, lets you save commits create branches and go back to earlier versions.

-GitHub is a website and online service that hosts Git repositories 
It stores your repository in the cloud so you can back it up, share it and collaborate with others.

--------------------------------------------------------------------------------------------------------

2-The four Git storage areas:
A-Working directory
B-Staging area "index"
C-Local repository
D-Remote repository

---------------------------------------------------------------------------------------------------------

3-Why pre-merge gates matter:
Pre-merge gates stop broken or insecure code
Like a committed password or a failing build from reaching the main branch before tests have checked it.
